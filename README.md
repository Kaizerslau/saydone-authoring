# SayDone authoring

SayDone authoring выполняется на C2: автор пишет полный исходный текст C2,
платформа разбирает и проверяет его, строит семантическую модель, а затем
детерминированный JSON-снимок для машинной границы и компилятора. JSON не
является основным исходным форматом новой ревизии.

Для ИИ начните с [AI_START_HERE.md](AI_START_HERE.md). Разработчику и автору
нужны [язык C2](docs/authoring/c2/LANGUAGE.md), [операции](docs/authoring/c2/CORE_OPERATIONS.md)
и [проверяемые примеры](docs/authoring/c2/examples/README.md).

Машинная граница описана в [справке C2](docs/authoring/c2/MACHINE_REFERENCE.md).
Материалы прежнего JSON-пути сохранены в [legacy/v1-json](legacy/v1-json/README.md)
только для исторической справки и миграции; не используйте их для новых C2-ревизий.
