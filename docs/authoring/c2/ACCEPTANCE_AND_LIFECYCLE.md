# Жизненный цикл и приёмка

Проверка работает с логическими ссылками на точную source и semantic revision.
Для replacement сервер сравнивает точные `sourceRevision` и `sourceChecksum`;
при несовпадении нужно получить актуальный source и повторить подготовку. Не
создавайте runtime, database или сгенерированные идентификаторы.

Приёмка относится к проверенной семантической ревизии. Parser, semantic
validation, compiler и подтверждение имеют разные границы: успешность одного
этапа не заменяет другой.
