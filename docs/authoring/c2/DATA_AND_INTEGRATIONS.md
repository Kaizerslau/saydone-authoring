# Данные и интеграции

`field` объявляет DataField для долговечных бизнес-данных. Используйте
`data.set` и `data.unset` в блоках. HTTP-ресурс объявляется через `http`, а
запрос и сохранение результата выполняются через `http.request` и `http.save`.

`saveState: true` сохраняет состояние блока; `saveState: false` не сохраняет
его. Не заменяйте эти значения несуществующими авторскими режимами.

`schedule.create` создаёт одноразовую задачу с независимой lineage. Таймер не
требует искусственного сохранения flow и не захватывает DataFields: для
долговечных бизнес-значений используйте DataFields. См. [core-flow.c2](examples/core-flow.c2).
