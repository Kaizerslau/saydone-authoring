# Машинная граница JSON

После разбора и семантической проверки C2 платформа детерминированно формирует
канонический JSON machine snapshot для последующей машинной обработки и
компилятора. Он полезен как точное представление проверенной семантики.

Для обычного создания и изменения не генерируйте JSON вместо C2 и не пытайтесь
восстанавливать C2 из произвольного JSON. Exact source revision/checksum
защищают replacement от устаревшего исходного текста.
