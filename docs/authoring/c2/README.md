# C2

C2 — текущий авторский язык SayDone. Полный текст проходит разбор, семантическую
проверку и компиляцию. Детерминированный JSON-снимок сохраняет машинную
семантику, но не заменяет авторский C2 source.

Начните с [языка](LANGUAGE.md), затем выберите [операции](CORE_OPERATIONS.md),
[данные и интеграции](DATA_AND_INTEGRATIONS.md) либо [маршрутизацию](ROUTING.md).
Готовые проверенные документы находятся в [examples](examples/README.md).
