# Проверенные C2 examples

Каждый полный документ ниже проходит production parser, semantic validation и
соответствующую компиляцию. Во всех named calls используются одна строка.

- [minimal.c2](minimal.c2) — минимальный документ и `message.send`.
- [core-flow.c2](core-flow.c2) — DataFields, rules, HTTP, schedule и subflow.
- [telegram-route.c2](telegram-route.c2) — Telegram-aware external route.
